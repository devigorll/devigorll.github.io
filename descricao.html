Análise Atrito (People Analytics)

Nesse projeto, eu usei Python e bibliotecas como Pandas e Scikit-Learn para criar um modelo de machine learning que calcula o risco de um funcionário sair da empresa. A ideia foi analisar o histórico do pessoal para prever o "tempo de permanência" de cada um e ajudar o RH a segurar os talentos antes que eles peçam demissão.

Análise Monitoramento Logístico

Nesse projeto, eu estruturei uma simulação completa de uma operação logística de entregas para o comércio eletrônico. Usei SQL para organizar o banco de dados e conectar as informações, e depois montei um dashboard interativo para acompanhar tudo em tempo real. O objetivo foi criar telas visuais onde a liderança consegue monitorar os prazos de envio, os custos de frete e o desempenho das entregas de um jeito bem prático, sem complicação.
